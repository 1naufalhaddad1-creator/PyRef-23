🐍 Apa itu Python?

Python adalah bahasa pemrograman yang dirancang untuk mudah dibaca dan ditulis. Diciptakan oleh Guido van Rossum pada tahun 1991, Python kini menjadi salah satu bahasa paling populer di dunia — dipakai oleh Google, Instagram, Netflix, NASA, dan jutaan developer lainnya.

💡 Mengapa Python?
Sintaksnya mirip bahasa Inggris biasa. Kamu bisa menulis program yang bekerja hanya dengan beberapa baris kode — jauh lebih sederhana dibanding bahasa lain seperti Java atau C++.

⚙️ Cara Instalasi Python

Python bisa diinstal di Windows, macOS, dan Linux. Pilih sistem operasimu:

1
Buka browser dan pergi ke python.org/downloads
2
Klik tombol kuning besar "Download Python 3.x.x"
3
Jalankan file .exe yang diunduh. PENTING: centang ☑ Add Python to PATH sebelum klik Install!
4
Tunggu proses instalasi selesai, lalu klik "Close"
5
Buka Command Prompt (tekan Win+R, ketik cmd, Enter) lalu ketik python --version untuk verifikasi
Verifikasi di Command Prompt:
C:\Users\Kamu> python --version
Python 3.12.0
C:\Users\Kamu> python
>>> print("Halo!")
Halo!
>>> exit()
1
Buka Terminal (Cmd+Space, ketik Terminal)
2
Instal Homebrew terlebih dahulu (package manager): ketik /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
3
Setelah Homebrew terinstal, ketik: brew install python
4
Verifikasi dengan: python3 --version
Alternatif: Download langsung dari python.org
$ python3 --version
Python 3.12.0
$ python3
>>> print("Halo!")
Halo!
ℹ️ Catatan
Di macOS, gunakan python3 bukan python karena macOS menyertakan Python 2 secara default.
1
Python biasanya sudah terinstal di Linux. Cek dulu: python3 --version
2
Jika belum ada, untuk Ubuntu/Debian: sudo apt update && sudo apt install python3
3
Untuk Fedora/RHEL: sudo dnf install python3

📦 Variabel & Tipe Data

Variabel adalah tempat menyimpan data. Di Python, kamu tidak perlu mendeklarasikan tipe data — Python akan menebaknya otomatis.

Tipe data dasar Python:
# Teks (String)
nama = "Budi"
kota = 'Jakarta'

# Bilangan Bulat (Integer)
umur = 20
tahun = 2024

# Bilangan Desimal (Float)
tinggi = 170.5
nilai = 9.8

# True / False (Boolean)
sudah_makan = True
hujan = False

# Cek tipe data
print(type(nama))    # <class 'str'>
print(type(umur))    # <class 'int'>
print(type(tinggi))  # <class 'float'>
✅ Aturan Nama Variabel
Gunakan huruf kecil dan garis bawah: nama_lengkap. Tidak boleh diawali angka. Hindari kata khusus Python seperti print, input, for, dll.
🖨️ Print & Input

print() menampilkan teks ke layar. input() meminta user mengetik sesuatu.

# print() dasar
print("Halo!")

# f-string — cara terbaik menggabungkan teks + variabel
nama = "Siti"
umur = 22
print(f"Nama: {nama}, Umur: {umur}")  # Nama: Siti, Umur: 22

# input() — selalu menghasilkan string!
nama = input("Masukkan namamu: ")
umur = int(input("Masukkan umur: "))  # konversi ke int
print(f"Halo {nama}, kamu berumur {umur} tahun!")
➗ Operasi Matematika
a = 10
b = 3

print(a + b)   # 13    — Penjumlahan
print(a - b)   # 7     — Pengurangan
print(a * b)   # 30    — Perkalian
print(a / b)   # 3.333 — Pembagian (selalu float)
print(a // b)  # 3     — Pembagian bulat (floor division)
print(a % b)   # 1     — Sisa bagi (modulo)
print(a ** b)  # 1000  — Pangkat (10³)
🔀 Kondisi — if / elif / else

Digunakan untuk membuat keputusan: "jika ini, lakukan itu; kalau tidak, lakukan ini".

nilai = int(input("Masukkan nilaimu: "))

if nilai >= 90:
    print("🏆 Luar Biasa!")
elif nilai >= 75:
    print("👍 Bagus!")
elif nilai >= 60:
    print("😊 Cukup, terus belajar!")
else:
    print("💪 Jangan menyerah, belajar lagi!")
⚠️ Perhatikan Indentasi!
Python menggunakan spasi/tab untuk menandai blok kode. Kode di dalam if harus diindentasi (biasanya 4 spasi). Ini berbeda dengan bahasa lain yang menggunakan {}.
🔁 Perulangan — for & while

Perulangan digunakan untuk melakukan sesuatu berulang kali tanpa menulis kode yang sama berkali-kali.

for — diketahui berapa kali ulang
# Hitung 1 sampai 5
for i in range(1, 6):
    print(i)
# Output: 1 2 3 4 5

# Loop isi list
buah = ["apel", "mangga", "jeruk"]
for b in buah:
    print(f"Buah: {b}")
while — ulang selama kondisi benar
# Hitung mundur
n = 5
while n > 0:
    print(n)
    n -= 1
print("🚀 Luncur!")

# Loop sampai input benar
while True:
    jawaban = input("Ketik 'ya': ")
    if jawaban == "ya":
        break  # keluar dari loop
📋 List, Tuple, Dictionary, Set

Struktur data bawaan Python untuk menyimpan kumpulan nilai.

# LIST — urutan yang bisa diubah, pakai []
buah = ["apel", "mangga", "jeruk"]
buah.append("durian")   # tambah di akhir
print(buah[0])           # "apel" (index mulai dari 0)

# TUPLE — urutan yang tidak bisa diubah, pakai ()
koordinat = (-6.2, 106.8)  # latitude, longitude Jakarta

# DICTIONARY — pasangan key:value, pakai {}
orang = {
    "nama": "Budi",
    "umur": 25,
    "kota": "Bandung"
}
print(orang["nama"])     # "Budi"
orang["umur"] = 26        # update nilai

# SET — kumpulan unik tanpa duplikat, pakai {}
angka_unik = {1, 2, 3, 2, 1}
print(angka_unik)          # {1, 2, 3}
🔧 Fungsi

Fungsi adalah blok kode yang bisa dipanggil berulang kali. Tulis sekali, pakai berkali-kali!

# Definisi fungsi dengan def
def sapa(nama):
    print(f"Halo, {nama}! Selamat datang!")

# Memanggil fungsi
sapa("Budi")   # Halo, Budi! Selamat datang!
sapa("Siti")   # Halo, Siti! Selamat datang!

# Fungsi dengan return value
def luas_persegi(sisi):
    return sisi * sisi

luas = luas_persegi(5)
print(f"Luas: {luas} cm²")  # Luas: 25 cm²

# Fungsi dengan nilai default
def salam(nama, waktu="pagi"):
    print(f"Selamat {waktu}, {nama}!")

salam("Roni")             # Selamat pagi, Roni!
salam("Roni", "malam")   # Selamat malam, Roni!
💥 Penanganan Error — try / except

Program bisa crash jika ada error. Gunakan try/except untuk menanganinya dengan elegan.

try:
    angka = int(input("Masukkan angka: "))
    hasil = 100 / angka
    print(f"100 / {angka} = {hasil}")
except ValueError:
    print("❌ Bukan angka yang valid!")
except ZeroDivisionError:
    print("❌ Tidak bisa dibagi nol!")
finally:
    print("Program selesai.")  # selalu dijalankan
